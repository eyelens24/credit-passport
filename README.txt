Credit Passport - hackathon mockup

Two ways to run it (no install needed):
1. credit-passport.html  - everything in one file. Double-click to open in a browser.
2. split/index.html      - the same site split into files:
     index.html  page structure and the five screens
     styles.css  all styling (colours are the variables at the top)
     engine.js   mock bank data, payee grouping, saved AI labels, risk engine and score
     app.js      screen logic, mocked integrations (Basiq, Yodlee, Tiimely), sliders, lender preview

Fonts load from Google Fonts, so you need internet for the proper typefaces.
The AI step uses saved labels ("Offline backup"); all bank connections are mocked.
